# 理论材料诊断的方法摘要

实验日期：2026 年 11 月 10 日。本文依据运行前协议及完成后的执行记录整理，供公开设计稿解释比较范围；精确数字见[统计快照](knowledge-diagnostic-statistics.json)，结果解释见[验证文档](../docs/validation-roadmap.md#3-理论卡与分析规范的诊断结果)。

## 目的与条件

比较新增理论卡和共用规范是否改善六维整场画像，以及选择性提供卡片是否减少输入。固定对话、目标说话者、任务、输出结构及候选—复核—必要修订流程。

| 条件 | 相对既有流程的变化 |
| --- | --- |
| baseline | 不加入新增卡片和规范 |
| all | 加入共用规范及本任务全部适用卡 |
| retrieved | 加入相同规范及任务/维度必需卡、关键词选中的专项卡 |

all 与 baseline 的差异是整个新增材料包；all 与 retrieved 主要检验筛选。retrieved 是确定性的任务标签和关键词选择，没有使用向量检索。

## 数据与选择

使用 [ASCEND 原始语料论文](https://aclanthology.org/2022.lrec-1.788/)对应的公开[数据发布版本](https://huggingface.co/datasets/CAiRE/ASCEND/tree/b65b9bb87a0412eb94a659660819060825e74b9f)。数据源按 CC BY-SA 4.0 发布。本仓库只提供方法和汇总，不重新发布转录文本。

六个录音块主题为科技、相互介绍、运动、求学、现实与信仰、自由与灵魂，涉及十二位互不重叠的说话者，排除既有开发对话的两位说话者。在生成结果前固定选择与目标：每场以发布原文单元较多的一位为目标，将立即相邻的同人片段合成发言块，保留原始 L 标注顺序及逐条映射。

录音块按发布标注重建，并非官方会话 ID。源数据的 train/test/validation 是语音识别划分，本次合并用于还原文本，不作为本项目的训练/测试划分。小幅时间戳反序不用于判断抢话或持续时间。材料属于同一提示式中英双语语料。

## 执行与保存

每条件每场一次完整运行，最多四次隔离阶段：候选、复核、必要时修订、最终复核。各阶段只收到该阶段原文、规则、schema 和所需的本运行候选，不读取其他条件结果。运行器与网页使用同一分析引擎，保留请求、响应、输入与实现快照、哈希和失败记录；没有调用外部模型 API。

有效比较的引擎 SHA-256 为 `0c53e889b37797d354db28e3b97411d84bab2587b5e7dab76970cc1cb185a0bd`。每次运行先固定知识包，选择轨迹只附最终结果。前期发现复核数据携带知识追踪信息后，中断受影响运行并全链重启，未复用旧候选。

五场 all/retrieved 的补充指令完全相同，因此去重。最后执行六场 baseline、六场 all 和一场 retrieved，共十三个有效条件、二十六次真实隔离阶段；全部在候选与复核后完成，没有触发修订分支。

## 评阅与计量

两个未接触条件映射的新模型评审各负责三场，从原文与匿名结果判断归属、时态、原话支持、过度推断、反例、遗漏及判断价值。每场只有一位模型评审；随后主协调者核读关键原话。此过程是诊断性模型评阅，尚不是独立人工评测。

输入输出字符按保存文件的 JavaScript UTF-16 长度计算。阶段输入包含 instructions/data/schema，评阅输入包含匿名包与量规；不含系统提示、派单包装和工具开销。隔离执行次数不是底层计费 API 请求数，墙钟时间含调度等待和主机暂停。

有效画像运行共二十六次执行；另有章节工程验收两次、匿名评阅两次、基础设施失败三次、版本中断两次，合计三十五次实际隔离执行。废弃尝试单列保留，不按语义质量差而剔除结果。

## 采用规则

以具体判断的支持、信息增量、遗漏及成本共同作决定。完整材料有局部收益但无总体赢家，因此保留为有限试用默认。筛选仅在必需规则保留、质量可接受且实测减少输入时才考虑取代完整卡集；当前不扩大向量库。
