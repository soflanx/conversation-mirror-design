# 对话镜像设计稿

**通过一场真实对话，让用户看清自己怎样表达、怎样与人互动，以及这些表现如何随情境变化。**

项目的起点是“你是什么样的说话者”。产品希望给出用户能理解、值得注意、可以回到原话核对的沟通画像：既回答“我显得友善、专业、主动还是克制”，也说明“我怎样接住别人的理由、什么时候改变回应、哪些做法容易带来误解”。

设计稿更新于 **2026 年 11 月 11 日**，对应当前已完成的原型及下一阶段设计。这里公开设计、取舍和验证摘要，应用源代码与完整实验运行档案不在本仓库中。

## 设计的几个核心决定

- **先传达判断。** 当前范围的综合画像和六项基础判断直接可见；原话、过程与运行记录逐层展开。
- **整体与局部分别分析。** 选择片段后给该段的画像；两段对照保留各自结果和情境差异。
- **以完整互动理解表达。** 将一个动作放回发起、回应、修正与后续中，解释它在这里起了什么作用。
- **用内容目录导航。** 目录显示标题、范围和划分理由；互动事件与变化可以跨越目录边界。
- **让证据改变结论。** 反例与独立审读用于修改判断正文，原话定位和程序校验为此提供基础。
- **按实际收益扩展架构。** 当前采用小型理论库与显式分析规范；更复杂的检索和索引通过质量、遗漏与成本对照决定是否采用。

## 当前状态

可体验的原型已具备导入、报告回看、六项沟通画像、内容目录、精确选区、两段对照、关键变化和原话回查。在线模型链路已经实现，运行开关仍为原型模式；新上传材料的在线分析和自由追问尚未开放。已有展示包含标明来源的预置内容、真实离线试跑和后续整理画像。

最近一轮检查通过 104 项工程测试，并完成桌面与手机交互核验。六场新对话的理论材料比较没有产生总体赢家，完整材料增加约 25.8% 请求字符。具体结果与采用决定见[验证文档](docs/validation-roadmap.md)，统计快照见[数据文件](evidence/knowledge-diagnostic-statistics.json)。
