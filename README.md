# 对话镜像设计稿

**和我共事或聊天，会给人什么感觉？**

选一位说话者，先看这次交流给人的一句印象和已有插图，再读六个角度的短评。想知道为什么，可以从判断点回原话。想了解双方同意了什么、还有什么待定，可以打开「对话经过」。

## 设计的几个核心决定

- **先说跟这个人交流是什么感觉。** 已有插图和整体印象一起显示，六维短评随后可见。点开短评可以核对本人原话及其上下文。
- **整体与局部各有依据。** 只核实了一项具体印象时，按该维度展示。选段和两段对照回到各自的原话。
- **以完整互动理解表达。** 将一个动作放回发起、回应、修正与后续中，解释它在这里起了什么作用。
- **用内容目录导航。** 目录显示标题、范围和划分理由；互动事件与变化可以跨越目录边界。
- **让证据改变结论。** 反例与独立审读用于修改判断正文，原话定位和程序校验为此提供基础。
- **按实际收益扩展架构。** 当前采用小型理论库与显式分析规范；更复杂的检索和索引通过质量、遗漏与成本对照决定是否采用。

## 当前状态

原型支持导入、报告回看、精确选段、两段对照和原话定位。完整演示随报告展示专属插图。启用实时模式并连接模型服务后，可手动生成分析、为旧报告补充合作印象以及自由追问。研究案例标明画像的整理来源，原始离线运行记录单独保存。

本轮完成桌面和手机首屏检查、原话回查以及独立模型试跑，工程验收通过 180 项测试。验证记录包含自动整体画像通过和只获准发布分项的案例。 [验证结果与实施路线](docs/validation-roadmap.md)
