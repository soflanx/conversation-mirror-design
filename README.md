# 对话镜像设计稿

**和我共事或聊天，会给人什么感觉？**

选一位说话者，先看这次交流给人的一句印象和已有插图，再读六个角度的短评。想知道为什么，可以从判断点回原话。想了解双方同意了什么、还有什么待定，可以打开「对话经过」。

设计稿更新于 **2026 年 11 月 19 日**。本仓库公开产品设计、技术取舍和验证摘要。

## 设计的几个核心决定

- **先说跟这个人交流是什么感觉。** 已有插图和整体印象一起显示，六维短评随后可见。点开短评可以核对本人原话及其上下文。
- **整体与局部各有依据。** 只核实了一项具体印象时，按该维度展示。选段和两段对照回到各自的原话。
- **以完整互动理解表达。** 将一个动作放回发起、回应、修正与后续中，解释它在这里起了什么作用。
- **用内容目录导航。** 目录显示标题、范围和划分理由；互动事件与变化可以跨越目录边界。
- **让证据改变结论。** 反例与独立审读用于修改判断正文，原话定位和程序校验为此提供基础。
- **按实际收益扩展架构。** 当前采用小型理论库与显式分析规范，独白调查以 BM25 检索原文。更复杂的检索和索引通过质量、遗漏与成本对照决定是否采用。

## 当前状态

原型支持导入文字、报告回看、精确选段、两段对照与原话定位。实时模式的一键分析可生成主报告、独白调查或说话者状态、章节分析、整场及分段插图，还有逐图的「为什么这样画」。录音导入有转录校对和原声回听。已保存录音的部分声音候选可在浏览器内扫描。 [技术架构与分析流程](docs/architecture.md)

一次六章独白的本机试跑完成了文本、图像和声学任务，报告及图注均可回查原话。现有比较实验、评估指标和下一步验证记录集中在验证文档。 [验证结果与实施路线](docs/validation-roadmap.md)
