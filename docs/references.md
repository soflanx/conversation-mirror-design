# 理论依据与采用方式

项目将七项研究整理为八张理论卡，用于明确概念、取证条件、排除条件和反例。**首页的六项沟通画像是本项目的产品框架；CSI 六维是另一组研究概念。** 二者都通过本场原文形成具体观察，不互换分数，也不因采用既有文献而自动获得文本测量效度。

| 理论来源 | 原文支持什么 | 本项目采用什么 | 需要保留的区别 |
| --- | --- | --- | --- |
| [Fiske、Cuddy、Glick 与 Xu，2002](https://doi.org/10.1037/0022-3514.82.6.878) | 群体刻板印象中的温暖与能力评价可以呈不同组合；研究讨论的是社会知觉。 | 分别寻找尊重、支持的表达，以及具体、有条理、有依据的解释，不把友善和专业合成一个好坏评价。 | 产品中的“专业严谨”指表达表现，与原研究的能力知觉并不等同；这篇研究没有验证本项目六维，也不认证个人实际能力。 |
| [Sacks、Schegloff 与 Jefferson，1974](https://www.conversationanalysis.org/schegloff-media-archive/simplest-systematics-for-turn-taking-language-1974/) | 会话轮替由参与者在局部互动中组织，并与其他言语活动的组织方式有所区别。 | 观察发起方向、重设问题、承接和让出空间，同时考虑访谈者、主持者等角色。 | 发言长短不能直接换成主导程度；原文没有提供本项目的个体主导性评分方法。 |
| [Clark 与 Brennan，1991](https://web.stanford.edu/~clark/1990s/Clark,%20H.H.%20_%20Brennan,%20S.E.%20_Grounding%20in%20communication_%201991.pdf) | 双方通过持续协调建立足以服务当前目的的共同理解；相关接续、确认和澄清可提供理解证据。 | 把被回应的内容、目标人的回应及必要后续连起来，具体说明接住了哪个问题、理由或限制。 | 理解对方说了什么、认同其观点、接受其建议和产生情感共鸣需要分别判断。 |
| [Schegloff、Jefferson 与 Sacks，1977](https://www.conversationanalysis.org/wp-content/uploads/2019/06/11_Schegloff_et_al_The_Preference_For_Self-Correction_in_the_Organization_of_Repair_in_Conversation.pdf) | 修复处理说、听和理解中的问题；发起修复与完成修复需要区分。 | 对照原说法、相关提示和后续改写，说明实际修改了什么。 | 论文中的 preference 指序列组织特征，不是人格偏好；纠正名称或误听也不能单独证明接受了不同立场。 |
| [Scherer，2005](https://doi.org/10.1177/0539018405058216) | 情绪、偏好、态度、心境和人际立场需要区分；主观感受是情绪过程的组成部分之一。 | 将表达基调与情绪线索分开，并标明主体、时间和证据类型，如本人自述或转录记录的外显表现。 | “喜欢这项运动”、讲述过去害怕或出现笑声，分别提供不同证据，不能直接汇成当下内心情绪曲线。 |
| [de Vries、Bakker-Pieper、Konings 与 Schouten，2013](https://journals.sagepub.com/doi/10.1177/0093650211413571) | CSI 提出表达活跃性、精确性、言语攻击性、探询倾向、情绪性、印象操控倾向六个领域，每个领域含四个分面；量表以自陈题项操作化。 | 形成“CSI 概念的文本观察边界”及“追查理由与限定结论”两张卡，为状态分析和具体判断提供观察角度。 | 原问卷的信效度与常模不能转移给本项目。项目不复制题项、不输出 CSI 测评分数，也不从一次谈话推断稳定人格。 |
| [Bunt 等，2010](https://aclanthology.org/L10-1385/) | 对话行为涉及交际功能、内容及前文依赖；功能片段可以比话轮更细，同一片段可以承担多种功能。 | 分开记录“谈什么”和“怎样回应”；允许同一句先确认再转问，保留跨章节的互动联系。 | 内容目录、功能单元和完整互动不必共享边界。采用这篇历史研究不表示系统已实现或符合现行 ISO 标准。 |

八张卡依次为：友善与专业表达、轮替与主导、共同理解、修复与修订、基调与情绪、CSI 文本观察、精确与探询、多功能片段。卡片中的证据要求、排除条件、反例及产品维度映射由本项目编写，后续需要通过真实对话的独立评测检验。
