# 对话镜像的验证结果与实施路线

更新日期：2026 年 11 月 11 日。

**目前已经完成可操作原型、工程约束检查和多轮真实语料开发诊断。下一步的核心是独立人工留出评测与真实用户任务验收。** 已有结果支持继续完善“判断优先、完整互动、局部独立取证、反例改变正文”的方向，同时要求按质量与成本决定是否增加检索和更多模型调用。

产品中有多种内容来源：人工示例、真实离线运行、后续整理画像和未来的在线新生成。五个研究展示案例来自三类对话，其中三份是同一场运动闲聊的不同运行或重组；不能当成五场独立对话。当前十三份研究案例整场/局部六维画像由独立展示文件整理，另有一份模拟画像，原始运行报告仍保留。

## 2 现有验证说明了什么

### 2.1 工程与交互

最近一次完整代码验收为 **104 项通过，0 项失败**，其中质量回归 11 项、后端 93 项；另完成类型检查和正式构建。这是应用当前版本的历史验收记录，本次设计稿整理没有重跑模型实验或修改应用代码。

工程检查覆盖原文解析、逐字引用、说话者、UTF-16 范围、顺序、输入隔离、补读预算、依赖撤下、不同选区的证据归属、目录覆盖、知识包复用、失败状态以及账号访问约束。测试主要使用固定输入和替身，证明这些程序规则得到执行。

浏览器检查单独覆盖：五个研究案例与完整示例、目录跳转、跨页选段、长发言内选字、两段对照、只一段有结果时的显示、重叠拒绝、键盘操作、原话定位，以及 320 像素手机宽度下的布局。这说明已检查的操作链路可用，尚不能替代新用户理解与任务完成率。

### 2.2 真实语料开发诊断

| 轮次 | 主要检查 | 得到的设计经验 |
| --- | --- | --- |
| 首次运动闲聊试跑 | 多阶段分析与充分配置的全文方案，核对内容和行为分类 | 全文也能恢复主要内容；引文匹配不能保证行为解释正确，应保留强全文基线 |
| 第二版分析 | ASCEND、ICSI、NARA 三类材料，重复运行及转录重组 | 一些互动机制可复现；综合层仍可能弱化重要局部机制；真实修订主要表现为范围限定 |
| CSI 与动态过程 | 同段多状态、轮内顺序、转录重组与笑声标记 | 状态需直接锚定原文，基调与情绪时间分开；分段不能决定观察存废 |
| 局部选区 | 单点、连续范围、非连续对照及失败案例 | 需要区分所选证据与背景，允许有界修订，同时保留被拒结果 |
| 六维画像 | NARA 局部画像及更新后的重跑 | 基础画像可以具体呈现，但内部审核仍会漏掉无依据的指代等问题 |
| 理论材料 | 六场新 ASCEND 对话的加载方式对照 | 某些反例更好地影响正文，同时存在退步和共同遗漏；尚无总体赢家 |
| 目录生成 | 一场求学对话的候选与复核 | 可生成连续三章并解释过渡；单场通过不构成分段准确率 |

这些是开发过程中发现错误、修复机制并比较方案的证据。不同轮次的样本、任务与版本不同，不合并计算一个系统总准确率。

## 3 理论卡与分析规范的诊断结果

### 3.1 比较如何进行

材料是六场此前未参与本项目提示调试的 ASCEND 录音块，涉及十二位互不重叠的说话者。固定原文、目标说话者、六维任务和审核流程，比较：

- `baseline`：既有流程，不加入新增理论卡与共用规范。
- `all`：新增共用规范与本任务全部适用卡。
- `retrieved`：相同共用规范，加按任务、维度和关键词选择的卡。

五场的 `all` 与 `retrieved` 补充指令完全相同，因此去重。最终是六场 baseline、六场 all，以及一场单独 retrieved，共 **13 个有效条件、26 次隔离阶段执行**。每个条件均为候选与复核各一次，没有触发修订或最终复核。

两个未接触条件映射的新模型评审各负责三场，收到原文和匿名编号结果；主协调者随后核读关键证据。每场只有一位模型评审，这一轮没有独立人工评分。协议摘要见[方法文件](../evidence/knowledge-diagnostic-protocol.md)，精确统计见[JSON 快照](../evidence/knowledge-diagnostic-statistics.json)。

### 3.2 结果与成本

| 对话主题 | 内容比较 | baseline 请求字符 | all 请求字符 |
| --- | --- | ---: | ---: |
| 科技与游戏 | 小幅偏好 all | 31,972 | 43,140 |
| 求学与学位 | 三组基本相当 | 18,374 | 28,817 |
| 自由与灵魂 | 各有优劣 | 37,762 | 49,042 |
| 相互介绍 | 基本相当 | 45,302 | 55,782 |
| 运动 | 各有优劣 | 76,208 | 87,860 |
| 现实与信仰 | 小幅偏好 all | 46,882 | 57,998 |
| 合计 | 2 小幅偏好，2 相当，2 各有优劣 | **256,500** | **322,639** |

完整材料比 baseline 多 **66,139 请求字符，增加 25.8%**。字符按保存请求的 JavaScript UTF-16 长度统计，含指令、数据和 schema，也受候选长短影响；不等于 token、费用或纯推理延迟。

新增材料的有用增量主要是让反例收窄正文：对方讲受挫经历后，目标转去谈游戏角色，all 将其写入“互动投入”的判断边界。baseline 已在亲和项承认未展开体谅，因此这项增量是把限制落实到了投入概括。另一场中，证明问题没有被直接回应，也成为修订积极接续判断的依据。

同时出现了退步：all 用“难以举例”的前半句支持一个判断，却忽略随后给出的具体故事。两组还共同漏掉了一次被当场纠正的记忆归属，以及邀请对方定义后简短否定便换题的过程。**审核通过后仍有遗漏，说明需要继续改善完整上下文读取与综合。**

检索只在求学场景产生不同材料：从七张适用卡减为六张，规范与卡片原文每阶段少 620 字符。两个阶段的序列化指令少 1,260 字符，较短候选另使复核输入少 91，总请求从 28,817 降至 27,466，减少 **1,351 字符，约 4.69%**。该场三组表现相当，其他五场没有检索压缩。

### 3.3 当前采用决定

保留 `all` 作为有限试用默认，保留内部对照开关，暂不扩大向量库。理由是完整材料提供了可追溯的观察约束，并在两场中改善反例的使用；目前接受已知的输入增量，继续检验具体收益。该轮结果没有证明理论卡普遍提高准确率。

这一轮 `all` 相比 baseline 同时增加理论和程序规范，无法单独估计理论的贡献。材料来自同一提示式中英双语语料，每条件一条执行链，下一轮应优先补充独立人工参考、其他会话类型和重复稳定性，而不是因混合结果持续追加同类试跑。

## 4 后续验收指标

用户体验与语义质量需要各自的证据，并在上线决策时一起考虑。

| 指标 | 怎样测量 | 对应问题 |
| --- | --- | --- |
| 判断理解 | 无讲解情况下复述主判断、当前范围和理由，记录用时与误读 | 信息是否真正被用户理解 |
| 范围操作 | 完成选段、对照、回到整场和原话定位任务 | 目录和选区是否直观 |
| 主张支持率 | 将公开文字拆成可判断主张，按充分支持、需限定、矛盾、资料不足评阅 | 结论是否有依据 |
| 关键事件召回 | 与评审在看模型结果前标出的重要内容和事件比较 | 是否遗漏值得知道的内容 |
| 必要上下文召回 | 检查发起、回应、后续和修订是否齐全 | 片段是否因缺上下文而误读 |
| 反例处理 | 找到相关反例，并检查是否修改对应正文、量词或范围 | 是否只挑支持自己的证据 |
| 严重归属与状态错误 | 错说话者、否定反转、过去当现在、提议当决定分别计数 | 高平均分是否掩盖严重错误 |
| 有效回答覆盖 | 有依据的问题是否回答，无依据部分是否保留具体缺口 | 是否靠空泛或拒答获得好看的支持率 |
| 边界与重复稳定性 | 合理重分段、同人转录合并、重复运行后的主张变化 | 结果是否过度依赖切法或偶然性 |
| 资源与失败 | 实际调用、输入输出、等待、失败、修订和重试 | 质量增量是否值得其成本 |

人工参考应由至少两位评审先独立读取原文，再处理分歧并保留合理的不同解释。按完整对话划分开发与留出数据；需要考察新说话者时进一步按说话者分组。指标分别报告事实、互动解释、模式和变化，统计以对话等独立单位为基础。

自动展示门槛在查看留出结果前按用途确定，同时约束严重错误和有效回答覆盖。当前尚未完成这套人工参考与门槛验收，不把已有模型审读的通过率当作放行指标。

## 5 下一阶段的实施顺序与决策门槛

| 阶段 | 具体交付 | 继续或调整的条件 |
| --- | --- | --- |
| P0 定义与参考 | 六维和关键互动的标注手册，纳入/排除/未知条件，人工参考样本 | 人工分歧能被解释，重要事件和反例有可用清单 |
| P1 新材料与用户任务 | 多类新对话的匿名评阅，整场/局部/对照的无讲解操作测试 | 同时获得有用判断、可接受支持度和重要内容召回；修复高频误读 |
| P2 在线运行准备 | 全链预算、可恢复任务、失败反馈、选区历史与数据使用说明 | 真实新材料完成端到端验收，失败和取消不会冒充成功，达到预先确定的语义门槛 |
| P3 取证与结构比较 | 强全文、固定窗口、互动结构、按任务补证据的对照 | 复杂方案须减少重要遗漏/误判或降低成本，否则保留简单路径 |
| P4 检索扩展 | 先比较确有卡集差异的任务，再检验原文关系与语义召回 | 必需规范和证据不丢失，质量可接受且有实测节省时才更换默认 |
| P5 长期与音频扩展 | 多场对话、不同伙伴及可用音频的单独方案 | 有适用数据与新的测量定义后，再讨论稳定画像和声学特征 |

P3 的方案比较要使用相同任务、原文和底层模型，给全文基线合理的输出与审核空间；既比较各自合理配置，也比较相近资源预算。只增加模型角色而没有证明误判或遗漏下降，不构成采用理由。

## 6 关键设计风险与修补方向

| 真实或可能反复出现的问题 | 对设计的影响 | 优先修补 |
| --- | --- | --- |
| 引文真实但只覆盖半句话 | 判断遗漏后续限定或例子 | 按主张补齐必要上下文，核查综合层是否丢信息 |
| 把相邻切片算作多次表现 | 夸大模式稳定性 | 合并转录碎片，按互动机会审查事件独立性 |
| 理论词替代具体判断 | 用户看到概念却看不清自己 | 每项先写具体判断与行为理由，术语进入详情 |
| 多模块反复读取全文 | 成本与延迟上升 | 先测资源，再比较共享证据表示与独立补查 |
| 整理展示看起来优于自动生成 | 对当前生成能力产生过高预期 | 保留内容来源，另评未经整理的新结果 |
| 新用户仍不清楚范围 | 误把局部判断当整场特征 | 持续显示范围，测试目录、选区与返回流程 |

本仓库附有方法摘要和统计快照。完整阶段请求、响应、实现快照、逐条原文映射与评阅文件另行保存，尚未打包为公开复现数据集。
